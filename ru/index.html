О себе

QA Automation Engineer с опытом работы в финтехе, платежах и CRM/ERP: на каждом продукте выстраивал QA-процессы и фреймворк. Пишет регрессионные наборы на Python с pytest и Playwright (async), тестирует API и проверяет итоговое состояние данных через SQL, прогоны организованы в GitLab CI с отчётами Allure. Совмещает автоматизацию с техническим лидерством: проводит собеседования, нанимает и онбордит QA-инженеров. Двигается в сторону AI-тестирования и автоматизации тестирования с применением AI.
